# Deriv Quant — Synthetic Indices Analysis & Execution

Real-time quantitative analysis and guarded execution for Deriv **Digital Options**
(Rise/Fall, Even/Odd, Over/Under, Matches/Differs) on exactly three synthetic families:

| Family | Symbols | Engine |
|---|---|---|
| Continuous (Volatility) | `R_10` `R_25` `R_50` `R_75` `R_100`, `1HZ10V` `1HZ25V` `1HZ50V` `1HZ75V` `1HZ100V` | `src/engines/continuousEngine.ts` — GBM, digit χ²/Z, Bollinger exhaustion |
| Step | `stpRNG`, `stpRNG2`–`stpRNG5` (when active) | `src/engines/stepEngine.ts` — run-length 0.5ᵏ, ρ(1), digit transitions |
| Jump | `JD10` `JD25` `JD50` `JD75` `JD100` | `src/engines/jumpEngine.ts` — jump detector, Poisson hazard, cushions |

Every candidate goes through `src/utils/evCalculator.ts` (P_be = S/W, EV, quarter-Kelly capped by max risk %)
and `src/lib/signals.ts` (availability, significance and trigger filters) before it can be marked
**HIGH EDGE / ACTIONABLE**.

## Run

```bash
npm ci

```

## Connecting your account

1. In the Deriv developer dashboard (developers.deriv.com) create an app (gives an **App ID**) and a
   **Personal Access Token** with the `trade` scope.
2. Click **Connect PAT**, paste both. The app calls `GET /trading/v1/options/accounts` with
   `Authorization: Bearer <PAT>` + `Deriv-App-ID`, then opens an OTP-authenticated WebSocket
   (`POST /accounts/{id}/otp`) for the selected account.
3. You always start on **Demo**. Switching to **Real** requires typing `REAL` in a confirmation dialog,
   and the whole UI gets a red border.

The token is held only in memory (Zustand store, no persistence) and sent only to `api.derivws.com`.
Reloading the page signs you out.

## Architecture

- `src/services/derivWs.ts` — WebSocket client: `req_id` correlation, persistent subscriptions re-sent
  on reconnect, exponential back-off, ping latency, client-side rate budgets (360/100/30/220 per minute).
- `src/services/derivRest.ts` — PAT REST calls (accounts, OTP).
- `src/services/session.ts` — public market socket (ticks, `contracts_for`, quotes) + trading socket
  (balance, buy, `proposal_open_contract`), guardrails, Stop All.
- Market data comes from the public socket (`wss://api.derivws.com/trading/v1/options/ws/public`), so
  analysis works without signing in.

## Safety rules built in

- Buys use a fresh proposal ID with `price = ask_price`; a `buy` is **never retried**. If the reply is
  lost, the purchase is looked up in `statement` instead (avoids duplicate contracts).
- Guardrails: max daily loss, max consecutive losses, minimum EV, minimum sample, minimum edge Z,
  max risk % per trade, one auto order at a time.
- **Stop All** halts execution, disables semi-auto, and tries to sell open contracts.

## A note on "edge"

Synthetic indices are generated by a certified RNG. Under that model every last digit is uniform and every
tick direction is a fair coin, while Deriv pays ≈95 % on 50/50 contracts (break-even ≈51.2 %). The
engines therefore estimate P_model from walk-forward back-tests, shrink it toward the theoretical
probability, and require statistical significance against break-even. Expect most rows to show
negative EV most of the time; that is the honest output, not a bug.

## Deploy

`.github/workflows/deploy.yml` builds a static export (`next.config.ts` → `output: "export"`) and publishes it to
GitHub Pages on every push to `main`. Enable it once under **Settings → Pages → Source: GitHub Actions**.
